# Movie behind-the-scenes edits

One JSON spec per Short, rendered with `python3 movie/bts.py edits_movie/<name>.json <out.mp4>`.
The source interviews are downloaded by hand (YouTube blocks downloads from the render machine) and are not committed.
Pick the moment from the transcript (`work_<name>/words.json`), keep it to the actor telling the story in their own words,
and check every claim in the hook against a published source before posting.
