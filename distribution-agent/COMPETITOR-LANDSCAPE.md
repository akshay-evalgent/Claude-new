# Competitor landscape: distribution-first AI agents

Researched 18 November 2026. Covers GitHub repositories, startups, commercial tools and human-in-the-loop services that do go-to-market for founders. Adds to the competitor table in `PLAN.md`.

## How far to trust this

- GitHub: star counts and descriptions were read from the GitHub API on 18 November 2026. No repository's code or README was read, so "what it does" is each author's own claim.
- Startups: the company's own page was read for about 35 of 45 products. Independent traction data and complaints exist for only five of them.
- Many pricing comparisons come from competitors' blogs.
- Launch dates are missing for most small tools.
- X posts and Indie Hackers could not be opened.
- For products with no independent reviews, the "weakness" column is a reading of the offer, not a reported complaint.

## 6. What the newest entrants do

- Ship as MCP servers or skills inside the founder's own agent.
- Read the codebase, not only the URL.
- Default to approval before posting, after complaints about Polsia and Okara.
- Add a human tier on top of the software.
- Try to tie actions to results: signups per ad, a verdict per change, outcome pricing.
- Bundle AI-answer checks as standard.
- Sell time-boxed campaigns instead of open subscriptions.

## 7. What nobody found is doing

| Gap | Detail |
|---|---|
| Diagnosis gate | No hosted product decides whether the problem is distribution, positioning or demand before it starts posting |
| Published fixed-price human sprint for solo founders | Human services start near $2,500, hide prices, or serve funded B2B |
| Revenue attribution for organic work | Nothing ties a reply, listing or launch to revenue for a solo maker |
| Honest cold-start handling | Tools assume accounts with history, or use rented ones |
| Marketplace listing optimisation | Only mobile app stores are covered; not Shopify, Chrome or MCP registries |
| Payout-aware marketplace choice | Not found anywhere |
| Customers for MCP servers and agents | Marketplaces give billing and a listing only |
| Sellers of templates, courses and ebooks | Almost everything targets SaaS |
| Non-technical sellers | Open-source options all need a coding agent |
| Published outcome data | Almost no vendor reports how many users got a paying customer |

## 8. What this changes for us

- Build on existing MIT skill packs. Do not rewrite them.
- Drop the claim that nobody serves AI-agent makers. `gtm-cofounder` does.
- Lead with what is open: a published fixed-price sprint, payout-aware marketplace choice, marketplace listings done for the client, and digital-product sellers.
- Publish outcome numbers from the first sprints. Almost no competitor does.
- Keep approval-first as a rule. The tools that post from rented accounts carry the ban risk.
- "Distribution-first" is unclaimed as a positioning phrase.
